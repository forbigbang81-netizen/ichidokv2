# ichidok — Termux Deploy Cheat Sheet

Save this file. Every command is copy-paste ready.

## 0. Get the project onto your phone

The project is packaged as `ichidok.tar.gz` (421 KB).

Download it from the sandbox preview's `download/` folder to your phone's
Downloads folder, then move it into Termux storage with:

```bash
termux-setup-storage
cp /storage/emulated/0/Download/ichidok.tar.gz ~/
```

(If `termux-setup-storage` prompts for storage permission, allow it.)

---

## 1. Install Node.js + Vercel CLI in Termux (one time)

```bash
pkg update -y && pkg upgrade -y
pkg install -y nodejs-lts git
npm install -g vercel
```

Verify:
```bash
node -v
vercel --version
```

---

## 2. Extract the project

```bash
cd ~
mkdir ichidok
tar -xzf ichidok.tar.gz -C ichidok
cd ichidok
```

---

## 3. Login to Vercel (one time)

```bash
vercel login
```

Pick **GitHub** or **Email**. The CLI will print a URL — long-press it in
Termux, choose "Open", complete the OAuth flow in your phone browser, then
come back to Termux. You should see `Congratulations! You are now logged in.`

---

## 4. Deploy (preview first, then prod)

Preview deploy:
```bash
vercel --yes --name ichidokV2
```

When you're happy, ship to production:
```bash
vercel --prod --yes --name ichidokV2
```

Your site goes live at `https://ichidokV2.vercel.app`
(if that name is taken Vercel picks `ichidokV2-<random>`).

---

## 5. Future updates

Every time you change something in the sandbox, re-download `ichidok.tar.gz`,
then in Termux:

```bash
cd ~/ichidok
# replace files with new tarball
tar -xzf ~/ichidok.tar.gz -C .
# redeploy
vercel --prod --yes --name ichidokV2
```

## Common Termux issues

**`vercel: command not found`** — close and reopen Termux, or run `source ~/.bashrc`.

**`EACCES: permission denied`** when installing vercel — run:
```bash
mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
npm install -g vercel
```

**`Cannot find module 'next'`** during the Vercel build — make sure you're
running `vercel` from inside the `~/ichidok` directory (the one with
`package.json` in it).

**Vercel build fails with TypeScript errors** — `next.config.ts` has
`typescript.ignoreBuildErrors: true`, so this shouldn't happen. If it does,
run `vercel logs <deployment-url>` to see the actual error.

**Login link doesn't open** — copy it manually: long-press the URL in
Termux, "Copy", paste into your phone browser.

## What's in the tarball

- All source code (`src/`, `public/`, `prisma/`)
- Build config (`package.json`, `next.config.ts`, `tsconfig.json`,
  `tailwind.config.ts`, `postcss.config.mjs`, `components.json`)
- Vercel config (`vercel.json` with name `ichidokV2` baked in)
- 508-anime database (`src/data/anime.json` — 921 KB, real Kitsu images)
- The `/api/player` proxy route (so episodes load)
- Deploy script (`scripts/deploy-vercel.sh`)

What's NOT in the tarball (regenerated by Vercel automatically):
- `node_modules/` (Vercel runs `bun install` or `npm install`)
- `.next/` (Vercel runs `next build`)
- Caches, logs, sandbox-specific files
